# Progress report - 13 Oct 2026

## Project question

We study human action recognition on a controlled 10-class subset of UCF101.
The first baseline asks whether a frozen Kinetics-400 pretrained video CNN,
R(2+1)D-18, can classify short clips from these classes after replacing and
training only the final classification layer.

## Dataset and split

- Dataset: UCF101, restricted to 10 classes:
  `Basketball`, `BasketballDunk`, `BodyWeightSquats`, `BreastStroke`,
  `FrontCrawl`, `JumpingJack`, `Lunges`, `PlayingGuitar`, `PlayingSitar`,
  `PushUps`.
- Split source: official UCF101 split 1.
- Test set: official `testlist01.txt`, restricted to the selected classes.
- Validation set: 20% of training groups per class, selected by group ID with seed 42.
- Train set: remaining official training groups.
- Leakage prevention: all clips from the same `(class, gXX)` group stay in the same split.

Current committed split size:

| split | clips |
|---|---:|
| train | 712 |
| val | 214 |
| test | 358 |

## Implemented data pipeline

The repository currently includes working code for:

- reading official UCF101 train/test lists;
- building a group-aware train/validation/test CSV;
- checking that all listed video files exist;
- decoding `.avi` clips with OpenCV;
- uniform or contiguous frame sampling;
- padding short clips by repeating the last frame;
- R(2+1)D-18 preprocessing: resize, crop, normalization;
- deterministic PyTorch `DataLoader`s;
- batch visualization through `scripts/visualize_batch.py`;
- automated smoke tests on tiny synthetic `.avi` videos.

## First baseline model

Implemented baseline:

- architecture: torchvision `r2plus1d_18`;
- intended weights: `R2Plus1D_18_Weights.KINETICS400_V1`;
- classifier head: replaced with a 10-class linear layer;
- default training setup: freeze backbone and train only `fc`;
- loss: cross-entropy;
- optimizer: AdamW;
- metrics saved: loss, accuracy, macro-F1, confusion matrix.

Run command once UCF101 is extracted:

```bash
python scripts/train_baseline.py \
  --video-root data/UCF-101 \
  --split-csv splits/split01_seed42.csv \
  --epochs 3 \
  --batch-size 8 \
  --num-workers 2 \
  --out results/metrics/baseline_r2plus1d18.json
```

For offline debugging without downloading pretrained weights:

```bash
python scripts/train_baseline.py \
  --video-root data/UCF-101 \
  --split-csv splits/split01_seed42.csv \
  --epochs 1 \
  --batch-size 2 \
  --num-workers 0 \
  --no-pretrained
```
